# 新遊戲方向：會被你改變的世界（2026-10-09 納可想的）

> 這個 repo 原本在做「會動的字」（已封存在 封存/文字世界/），2026-10-09 納可決定新遊戲也做在這裡。名字還沒定。
> 這裡只放納可講過、點過頭的東西。

## 一句話

玩家在一個 2D 世界裡，做什麼都會改變這個世界的生態；玩家玩的是觀察「做什麼會造成什麼」。

## 已經定下來的

- 視角：橫卷軸，像《泰拉瑞亞》。參考《我的世界》《泰拉瑞亞》，差別是在泰拉挖出來的洞就停在那裡，這裡的世界會回應你。
- 畫面：像素風，世界由一格一格的方塊組成，以「格」為單位模擬。不做《Noita》那種每顆像素都在動的物理。
- 玩家角色在世界裡面。多人、NPC 以後再說。
- 世界上任何東西都能改變、也都能改回去，但不順心如意：A 變 B 和 B 變 A 要花的心力可能完全不一樣。
- 每種環境、生物、物資都有自己的出現條件，條件變了就會變成別的東西。
- 使用本身就會造成改變。
- 改變沒有好壞之分，只是「變成別的」。（納可：不要變成環保遊戲）
- 這個世界的生態循環和演化速度是地球的很多倍，大概「一年變一天」都不只。
- 核心玩法是觀察：做什麼會造成什麼。
- 世界只在玩家睡覺的時候推進。
- 玩家越累，睡得越久（真的很久），世界推進越多。
- 沒有黑夜，地下才是黑的。
- 天色有四段：晨、亮、昏、暗，各有不同氣氛，也會影響生態。
  - 醒著時天色在轉，影響的是「誰出來活動」（哪些蟲在飛、哪些花開著）；睡著時才是真正的改變（長出什麼、消失什麼、演化）。
- 時鐘：圓形，用 X 切成四塊。X 的兩條線靠近水平，上下兩塊窄（晨、昏），左右兩塊寬（亮、暗）。整個 X 順時針轉一點，看起來歪歪的。
