## 2026-10-09 第一次談新遊戲

### 起點
- 納可問：有沒有人做過真的類世界的沙盒模擬，重點是「你真的一直在改變這個世界的生態」。
- Claude 舉過的參考：《Eco》（多人、污染、隕石倒數，最接近）、《SimEarth》（上帝視角改星球）、《WorldBox》（上帝沙盒）、《Terra Nil》（把廢土修回去再離開，有固定終點）、《Equilinox》《The Sapling》（小生態箱）。
- Claude 的判斷：大部分遊戲要嘛玩家是天上的神，要嘛有「修好了」的結局；「一個人在世界裡、每個動作都留下痕跡一路連鎖」這個位子還沒被做滿。

### 納可講的核心（都已寫進 生態沙盒.md）
- 玩家角色在裡面；多人、NPC 以後再說。
- 任何東西都可改變、可逆，但不順心如意，A→B 和 B→A 心力可能完全不同。
- 每種環境、生物、物資有各自的出現條件，改變就變成別的。使用本身就會造成改變。
- Claude 補的說法：現實生態叫「遲滯」，草原變沙漠快，變回去慢。

### 玩法怎麼談出來的
1. 納可問「玩法是什麼」。Claude 提：玩家有需求 → 搞懂條件 → 把地推過去 → 原本的東西消失 → 取捨。還提了「一連串要做出來的東西（工具要三種材料，三種環境互相衝突）」。納可沒接這條。
2. Claude 在談視角時把「規劃土地」當成核心，納可指出他沒說過。這是 Claude 的錯：把自己的提案當定案拿來推論。
3. 納可說像《我的世界》《泰拉瑞亞》，但泰拉挖出來的洞就那樣了。→ 定橫卷軸。Claude 舉的例子：挖洞 → 積水 → 長苔蘚 → 引來蟲 → 想填回去土會塌或長出別的。
4. 納可：演化速度是地球很多倍，年→日都不只。
5. 納可想「目標是活下去嗎」。Claude 說適合當底，但用了「今天拿的會毀掉明天要的」這種說法，納可說「感覺變成環保遊戲」。→ 改成：改變沒有好壞，只是變成別的；每種環境有自己獨有的資源。
6. 納可發現：玩家其實在玩觀察，做什麼會造成什麼。→ 這是目前的核心。Claude 舉的參考：《Noita》（東西互相反應、一直實驗）、《Outer Wilds》（進度是腦袋裡的知識）。
7. 活下去目前退到後面，還沒定要不要、怎麼做。

### 畫面與時間
- 2D 比較好做好玩。俯視角 vs 橫卷軸：一度難選，最後因為參考是泰拉而定橫卷軸。
- 像素：要的是「像素風＋格子世界」（像泰拉），不要《Noita》那種每顆像素都在模擬。
- 納可：玩家睡覺時世界才變。
- 納可：越晚睡推進越多 → 再修正成「太累了所以睡了好久（真的很久）」，重點在累，熬夜只是累的來源之一。
- 納可：不一定有夜晚 → 再修正成有晨、亮、昏、暗四段天色，各有風情，只是沒有黑夜，地下已經是黑的。天色會影響生態。
- Claude 提、納可沒反對：醒著時天色影響「誰出來活動」，睡著才真正改變世界。（已寫進 生態沙盒.md）
- 時鐘：X 切四格，上下小的是晨昏，左右大的是亮暗，整個 X 順時針轉一點。

### Claude 提過、還沒拍板的
- 條件種類一開始少一點（水、光、肥度、溫度三四種），東西先做十來種，免得玩家看不出因果。
- 條件數字藏起來，玩家只能看現象推規律；給一本筆記記下發現，筆記就是進度。（納可沒回應）
- 「條件表」做法：每樣東西寫「要什麼條件才出現」和「存在時會把環境推往哪裡」。
- 世界推進速度要拿捏，太快看不出因果，等做出來再調。
